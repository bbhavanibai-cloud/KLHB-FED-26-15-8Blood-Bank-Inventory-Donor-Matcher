Project Abstract/Statement:
*Blood Bank Inventory and Donor Matcher* is a Java-based system designed to make blood bank management easier, faster, and more organized. In many blood banks, maintaining accurate records of blood groups, available units, donor details, and blood requirements can become difficult when handled manually. Finding a suitable donor during an emergency can also take valuable time. This project aims to solve these problems by developing a simple Java application that stores and manages donor and blood inventory details, updates blood stock when blood is collected or issued, and searches for suitable donors based on the required blood group. The system uses basic Java concepts such as *classes, objects, arrays, methods, loops, conditional statements, and file handling* to manage the information efficiently. By automating these routine tasks, the project helps reduce errors, saves time, improves blood availability tracking, and makes the process of finding a suitable donor more organized and reliable.
